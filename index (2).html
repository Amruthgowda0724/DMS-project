Predicates & Quantifiers — Refresher

A predicate P(x) is a statement whose truth depends on the variable x. The domain of discourse defines all valid values for x.

Universal Quantifier ∀x P(x)
∀x P(x) ≡ P(d₁) ∧ P(d₂) ∧ … (over finite domain)

TRUE only when P(x) holds for EVERY element in the domain.

Existential Quantifier ∃x P(x)
∃x P(x) ≡ P(d₁) ∨ P(d₂) ∨ … (over finite domain)

TRUE when P(x) holds for AT LEAST ONE element in the domain.

🔍 Rule Comparison Table

Rule Abbreviation Given Infers Key Condition
Universal Instantiation UI ∀x P(x) P(c) c is any element in the domain
Universal Generalization UG P(c) ∀x P(x) c must be ARBITRARY (no prior conditions)
Existential Instantiation EI ∃x P(x) P(c) c must be a FRESH, new constant symbol
Existential Generalization EG P(c) ∃x P(x) c is any specific known element

⚡ De Morgan's Laws for Quantifiers

¬∀x P(x) ≡ ∃x ¬P(x)

It is NOT the case that all x satisfy P(x) = there exists some x that does NOT satisfy P(x)

¬∃x P(x) ≡ ∀x ¬P(x)

There does NOT exist an x satisfying P(x) = for all x, P(x) is false

🔗 Bound vs. Free Variables

Bound Variable: A variable that is within the scope of a quantifier.

∀x P(x) → x is bound

Free Variable: A variable that appears without any quantifier governing it.

∀x P(x, y) → y is free
